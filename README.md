# Discord Bot Template

This project is a simple Discord bot template, created with the idea of having a reusable base to develop different bots without having to start from scratch every time.

I originally started working on it to build a foundation that I could reuse across multiple projects. However, I eventually left it unfinished and never got around to developing it further.

I'm making it public in case someone finds it useful as a starting point for their own Discord bot or wants to reuse parts of the code in another project.

Feel free to use it, modify it and build upon it!

## .env
```env
BOT_TOKEN=your_secret_bot_token
```
